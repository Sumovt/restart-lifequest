# 重新出發 · LifeQuest

RPG 風格角色養成習慣追蹤器，靈感來自 LifeQuest 類遊戲。

把真實生活目標變成可升級的角色技能：

| 技能 | 對應目標 |
|------|----------|
| 💰 財務自由 | 每月儲 2 萬買美債 → 2030 年 100 萬+ |
| 🏋️ 身型鍛鍊 | 每週 Gym 2–3 次 → 體重 70kg |
| 🎸 結他之路 | 能即興與作曲 |
| 📚 理論深造 | 找到適合自己的理論並持續深造 |
| ✍️ 副業輸出 | 零成本、低時間的內容輸出 |

## 功能

- 角色面板：頭像、名稱、總 XP、整體等級、連續天數
- 五大技能各自獨立 XP 與等級
- 今日任務板：手動加入 / 隨機任務板
- 完成任務即時獲得 XP
- 冒險日誌、成就殿堂
- 資料本地儲存，可匯出 / 匯入 JSON
